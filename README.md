# LifeOS — Personal Command Centre

> AI-powered personal operating system for tasks, goals, habits, notes, calendar and intelligent planning.

Built for the **£1 Million App Challenge**.

## Features

- Beautiful Dashboard
- Task Management
- Calendar
- Notes
- Goals
- Habits
- AI Assistant (natural language → real actions)
- Global Search
- Analytics
- Dark / Light mode
- Mobile-first
- Persistent localStorage
- Onboarding

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub → Import on Vercel (free).

## Tech

Next.js 16, TypeScript, Tailwind 4, Zustand, date-fns, lucide-react, next-themes
